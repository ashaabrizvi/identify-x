# Xaily — Identify X

A daily deduction game. One cryptic description. One answer. Pure reasoning.

## How it works

Each day, everyone gets the same question. Three clues describe something — a concept, event, person, or idea — without ever naming it. Your job is to figure out what **X** is.

- Start with **one clue**
- Guess correctly → earn up to **3 points**
- Reveal more clues for help — but each one costs a point
- No time limit. No multiple choice. Just think.

## Features

- 30 hand-crafted questions across Science, History, Politics, Biology, Philosophy, Economics, Technology, and Culture
- Daily rotation — same X for everyone each day
- Streak tracking (no account needed)
- Share your result
- Works offline (PWA)
- Free. No ads. No login.
